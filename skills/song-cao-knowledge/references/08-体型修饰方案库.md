# 08 体型修饰方案库（痛点级·让衣服为身体服务）

> **定位**：02-服饰形制 §七 是"**风格标签级**"映射（柔和曲线型→改良 X 型褙子）；本库补"**痛点级**"映射（宽肩→V领落肩、大腹→高腰线）——CAO 从"画好看的衣服"升级到"通过设计修饰人体"（2026-10-01 创始人引入，Gemini 建议校准落地）。
> **素材来源**：AIS（《与纽约形象大师对话》Always In Style）身体线条系统 + 服装线条同轴匹配（`~/.agents/skills/always-in-style` ch02/ch03）+ 02 §七 slim_goal 修正表 + 宋式形制解。
> **核心原则（继承 02 §七）**：映射锚点是"**宋式形制解 × 体型痛点**"，**不是**西方体型理论（Kibbo/弧线口袋/荷叶边）——宋式"柔和"靠直领软开合+窄袖+收腰+留白灰调，不靠西方弧线装饰。
> **接入**：出图前结构简报执行"体型诊断"（诊断结论写入 prompt 前段）+ 视觉权重分布 + 修饰合规 3 问反思（见 §五）。
> **覆盖面（2026-10-01 补全）**：男女性别分型 + 女性胸型（大/小/下垂）+ 男性体型 + AIS 6 档身体线条（第一坐标）+ 骨架维度 + 7 大类 20+ 痛点。

## 〇、AIS 身体线条 6 档（第一坐标，先于痛点判断）

> 痛点修局部，线条定轮廓。**任何体型诊断先定线条档**（决定大廓形），再查痛点映射表（修局部细节）。
> 判定：穿影子/紧身衣看整体轮廓走向（肩-腰-臀外缘直曲）；**拿不准看脸型**（方/长/尖下巴=直线系，圆润=曲线系）。

| 身体线条档 | 特征 | 宋式大廓形解 | 反模式（错轴） |
|---|---|---|---|
| **棱角直线型** | 最锐利、骨感分明 | H 型直筒长褙子（112-131cm）、立领、直线条 | 软塌垂坠面料 |
| **直线型** | 轮廓平直、无明显收放 | H 型 + 圆领/直领 + 窄袖 14cm | 曲线剪裁 |
| **柔和直线型** | 直中带柔（大众安全区） | H 型微 X、直领软开合 2-3cm | 两端极端都显违和 |
| **混合型** | 直曲特征都不极端 | 可直可曲，按场合选 | 无 |
| **柔和曲线型** | 圆润为主、少棱角 | X 型收腰 + 直领软开合 + 窄袖 16cm + 侧开衩 | "荷叶边/弧线口袋"（西方理论，拒） |
| **曲线型** | 最圆润、无明显棱角 | X 型深收腰 + 垂坠面料 + 大下摆 | 直线硬挺廓形 |

> **骨架 × 布料 × 线条**（AIS ch02）：>170cm 大骨架能撑重料+挺直线；160-170 普通；<160cm 小骨架配轻料+垂坠。骨架影响面料克重，不影响线条档。

## 一、女性体型痛点 → 宋式修饰解（核心）

> 使用：含多个痛点时按 **首要修饰原则** 取 1-2 条作结构约束（不叠加过多——同图模型指令预算规律）。

| 体型痛点 | 修饰原理（为什么） | 宋式结构解（CAO 可调用） | prompt 约束（Constraint） |
|---|---|---|---|
| **宽肩** | 模糊肩线、纵向切割 | V 领开合加深 + 落肩袖（avoid 垫肩/泡泡袖）；褙子直领改 V 领 2-3cm | `deepen V-neck opening, dropped shoulder, NO shoulder padding` |
| **窄肩/溜肩** | 增加肩部量感、提肩线 | 直领平齐领 + 窄袖 16-18cm（靠袖笼撑肩）+ 挺括面料；avoid 深 V 领 | `defined collar, structured fabric adds shoulder presence, avoid deep V` |
| **大腹/腰粗** | 视觉焦点前移、腰线重塑 | 高腰线（胸下腰线）+ 前襟重叠（长褙子对襟遮腹）；avoid 横腰带/紧腰 | `empire/high waistline below bust, front overlap conceals abdomen, avoid horizontal waistband` |
| **腰细但胯宽（梨形）** | 强调腰线、分散胯宽 | X 型收腰（省道显腰）+ 下摆外扩 + 旋裙三片错叠遮胯（02 §7.3）| `cinched waist + flared hem, panel overlap conceals hips` |
| **腰长腿短** | 拉高腰线、视觉上移 | 高腰旋裙/高腰裤 + 短衣长（及臀）+ 竖线条 | `high waistline, short jacket to hip, vertical lines` |
| **粗腿/腿短** | 纵向拉伸、线条遮蔽 | 直筒长褙子 112-131cm 垂至膝下遮腿 + 侧开衩（露小腿线）；avoid 卡膝裙长 | `long A-line to mid-calf, side slit shows leg line, vertical lines` |
| **细腿/腿过于骨感** | 增加腿部量感 | 直筒裤/长裙遮挡 + 面料挺括 | `straight trousers or floor-length, structured fabric` |
| **圆肩/虎背** | 增加挺括感、肩线清晰 | 挺括面料（精纺羊毛/华达呢）+ 领部挺括线条（改良直领） | `crisp structured fabric, defined collar line, upright shoulder` |
| **胸大** | 视觉重心下移、避免膨胀 | 深 V 领/直领开合（露颈线拉长）+ 腰线明确（X 型收腰显胸腰差）+ 前襟直线条（avoid 高圆领/胸前横褶/紧身）| `V-neck elongates, defined waist cinch, NO high round neck, NO chest gathers, clean front panel` |
| **胸小** | 增加胸前量感、立体 | 胸前细褶/风琴褶（体积感）+ 高腰线 + 挺括面料（撑形）；avoid 深 V 贴平 | `subtle chest gathers/pleats add volume, high waistline, structured fabric` |
| **胸下垂** | 上托视觉、重心上移 | 高腰线（帝国式腰线在胸下托举）+ V 领（露锁骨拉视线）；avoid 低腰线 | `empire waistline supports bust, V-neck shows collarbone, avoid low waist` |
| **臀扁/胯窄** | 增加臀胯量感 | 下摆外扩 A 型 + 褶皱/褶裥臀位 + 旋裙错叠 | `flared A-line hem, subtle hip gathers` |
| **手臂粗** | 模糊上臂线条 | 中长袖（七分/八分）遮半臂 + 袖口 14-16cm 微收；avoid 无袖/紧身短袖 | `mid-length sleeves to elbow, relaxed sleeve width, avoid sleeveless` |
| **脖子短/脸圆** | 拉长颈部线条 | V 领/直领深开合 + 无高领；avoid 立领紧贴 | `open neckline elongates neck, NO tight stand collar` |
| **个子矮（<158cm）** | 拉高腰线、显腿长 | 短衣长（及臀）+ 高腰旋裙 + 竖线条（02 §7.3 显高）| `high waistline, short jacket to hip, vertical lines, avoid midi length` |
| **个子高（>172cm）** | 柔化纵向、避免单薄 | 长褙子 112-131cm（垂坠压比例）+ 横线条微点缀 | `long line, slight horizontal accent balances height` |
| **整体圆润（微胖）** | 纵向显瘦、藏肉 | X 型收腰（不是 H 型压扁）+ 直领深开合 + 垂坠面料；avoid 紧身/大花 | `cinched waist, vertical lines, draped fabric, avoid tight fit` |
| **整体偏瘦（骨感）** | 增加量感、避免单薄 | 宽大廓形 + 垂坠面料 + 多层叠穿（长褙子+内搭）| `generous volume, layered draping, soft fabric` |

## 二、男性体型痛点 → 宋式修饰解

> 男性版：宋式男装以圆领袍/直裰/道袍为骨架（02 §4.2B），修饰逻辑同 AIS（线条定廓形 + 痛点修局部）。

| 体型痛点 | 修饰原理（为什么） | 宋式结构解（男） | prompt 约束（Constraint） |
|---|---|---|---|
| **啤酒肚/腰腹赘肉** | 遮腹 + 纵向拉长 | 直裰/道袍直筒廓形（垂坠遮腹）+ 深色 + 无腰线；avoid 收腰/横带 | `straight vertical robe conceals abdomen, dark muted color, NO waist cinch` |
| **窄肩/溜肩（上身单薄）** | 增加肩部量感 | 圆领袍挺括肩线 + 挺括面料（撑肩）+ 平直领口 | `defined shoulder line, structured fabric adds upper-body presence` |
| **宽肩（倒三角）** | 柔化肩线 | 圆领落肩 + 深色肩部 + 纵向线条；avoid 垫肩 | `softened shoulder, vertical lines, avoid padding` |
| **粗腿/腿短** | 纵向拉伸 | 直筒长裤 + 长衣（及臀下）遮腿 + 深色 | `straight long trousers, elongated garment, vertical lines` |
| **个子矮（<168cm）** | 拉高比例 | 短衣长（及臀）+ 高腰裤 + 竖线条 | `short jacket to hip, high-waist trousers, vertical lines` |
| **胸平/上身薄** | 增加胸廓量感 | 圆领袍胸前提褶/垂坠 + 挺括面料 | `subtle chest drape, structured fabric` |
| **肚子大+腿细（苹果型男）** | 遮腹不放大腿 | 直裰遮腹 + 直筒裤（不紧身）| `robe conceals abdomen, straight not tapered trousers` |
| **脖子长** | 平衡颈长 | 立领/圆领微高领口（无领袍改立领 3-4cm）| `slight stand collar balances long neck` |

## 三、复合体型判定示例（诊断流程）

> 多个痛点组合时：**线条定大廓形（§〇）+ 首要痛点 1-2 条修局部（§一/§二）**。

**示例 1 · 女性「圆肩、腰细、胯宽」（C-0001 林女士 / 黛青阁客群）**：
```
线条档：柔和曲线型 → X 型收腰大廓形
首要痛点：① 圆肩→挺括面料+领部线条 ② 腰细胯宽→X 收腰+下摆外扩+旋裙遮胯
Constraint: crisp structured fabric + defined collar; cinched waist + flared hem + panel overlap conceals hips
Visual Hierarchy: Emphasize waist cinch + vertical panel lines; de-emphasize hip width via flowing A-line
推荐款：改良 X 型长褙子 + 旋裙（三片错叠）
```

**示例 2 · 女性「胸大 + 腰粗」**：
```
线条档：柔和曲线型 → X 型
首要痛点：① 胸大→V 领+腰线明确（避免胸前膨胀）② 腰粗→高腰线+前襟重叠
Constraint: V-neck elongates, high waistline below bust, clean front panel, NO chest gathers
Visual Hierarchy: Emphasize neckline + waist cinch; de-emphasize bust and abdomen via vertical opening
推荐款：V 领改良褙子 + 高腰旋裙
```

**示例 3 · 男性「啤酒肚 + 窄肩」**：
```
线条档：直线型 → H 型直裰
首要痛点：① 啤酒肚→直筒垂坠遮腹 ② 窄肩→挺括面料撑肩
Constraint: straight vertical robe conceals abdomen, defined shoulder line, structured fabric
Visual Hierarchy: Emphasize vertical line of robe; de-emphasize abdomen and shoulder narrowness
推荐款：直裰（垂坠遮腹）+ 挺括圆领袍肩部处理
```

## 四、视觉权重分布（动作 B，Gemini 建议校准）

> AI 画"显胖的衣服"根因=不懂视觉焦点。要求：**拉大修饰区域的视觉权重，减小痛点区域的视觉权重**。

- **实现**：image_mode prompt 加入 `[Visual Hierarchy: Emphasize <修饰元素> (vertical folds / opening placket / waist cinch) to distract from <痛点区域>]`
- **示例**（宽肩+大腹）：`[Visual Hierarchy: Emphasize vertical center placket + high-waist definition; de-emphasize shoulder width and abdomen via deep V-neck and flowing front overlap]`
- **对应宋式**：纵向线条=直领对襟中线/侧开衩/竖褶皱（02 §七 显瘦"纵向线条拉长"的 prompt 化）

## 五、修饰合规性反思 3 问（动作 C，升级第 3 层自检）

> 出图后加 3 问（并入 C1-C4 前或后，权重同 C 轨）：

| # | 反思问 | 过=✅ / 不过=❌ |
|---|---|---|
| **M-1 线条逻辑** | 是否用了横向线条（横腰带/横纹样/横拼接）**加剧**了体型弱点？（宽肩者加横条=雪上加霜；大腹者横腰带=放大）| |
| **M-2 空间留白** | 痛点区域（腹部/胯部/胸前）是否有足够的"视觉呼吸感"（留白/褶皱/垂坠）来掩盖？| |
| **M-3 比例修正** | 腰线位置是否符合修饰需求？（大腹者胸下腰线而非自然腰线；梨形者腰线收束；胸大者腰线明确显胸腰差）| |

## 七、与现有体系的关系

- **02 §七**（风格标签级映射）= 本库的上一级：body_line→结构解；本库=痛点级：痛点→宋式修饰解
- **05 方法库**：诊断流程并入第 1 层；修饰合规 3 问并入第 3 层（C1-C4 之后或同权）
- **S 轨**（成衣功能）：本库是 S 轨的"穿着者维度"补充（S 轨目前验服装本身：腰身/肩带/开衩；本库验"服装 vs 穿着者体型"）
- **AIS**（always-in-style skill）：身体线条 6 档 + 骨架 + 同轴匹配 = 本库的理论底座（宋式解是它的落地）
- **persona/schema**：persona 出图三步加"体型诊断"；schema card 已有 body_line/slim_goal 字段（02 §7.4 SOP 已读档）
- **分性别**：§一 女性（含胸型大/小/下垂 3 项）、§二 男性（含啤酒肚/窄肩等 8 项）——出图性别由"给谁穿"的 Q1 决定，男装走 §二
