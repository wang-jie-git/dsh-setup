# 06 气韵系统（v3.3 新增，2026-09-26）

> **定位**：v2.0（20 号方案）落地的是"转译的**判据侧**"——05 方法库 M 条款（判断依据）、T1–T6 转译完成度（事后打分）、NEG 库（反例）。但它们都是**校验时用**的，不是**出图时用**的。出图侧长期停在"临场手写 prompt 去试"（v1 复古→v5 转译，每次靠手感）。
>
> 本篇补上欠账：把 v2.0 已有的 M 条款 + T 判据 + 01 色彩 + 03 构图**重组成出图侧的"设计系统"**——气韵三层坐标（事前定目标）+ 活参数（把 M 条款转成可注入的活配方）+ 设计配方卡（款 × 气韵 × 构图活方法 × 色彩灰度系统）。**不新造判据，全部引用 v2.0 已有资产**。
>
> 核心命题（引 20 号方案来源文案）：**追求"不可翻译的东方性"——不是靠符号证明中式，是越松弛越回到自己的感受，作品反而越有文化性。**

## 〇、气韵三层坐标（出图前必须落在哪一层）

| 层 | 状态 | 判断 | 处理 |
|---|---|---|---|
| **① 符号拼接** | 盘扣+立领+缠枝纹+刺绣+缃黄堆砌直陈（当"中式"标签） | "符号堆砌/唐装/影楼新中式" | **禁**（回炉；2026-09-30 修正：禁止的是堆砌，立领/盘扣可作改良结构如改良对襟/盘扣→现代纽扣） |
| **② 泛现代** | 去掉所有符号，但空洞无内在气韵 | 西方看"就一件 generic 现代款，说不出为什么好" | **不够**（干净但平庸，无记忆点） |
| **③ 不可翻译的东方静气** | **一眼可感中式气质**、3 秒"静下来"、有"说不清的静气"（2026-09-30 修正：目标是"看得出中式气质但说不出为什么"，非"看不出中式"） | 中西方都看"好静、好高级、看得出是中国/宋韵但说不出为什么" | **目标** |

> **关键**：v2.0 的 T 判据 + M 条款**只能判"是否①"（失守）和"是否达标"（T 完成度），判不了"② 还是 ③"**——因为判据全是"有没有做减法/留白够不够"这种可量化项，量化项天然停在上限②。③ 靠的是**活参数**（下节），不是量化项。

## 一、活参数（把 M 条款转成出图可注入的"活配方"）

> 全部引自 v2.0 已有 05 M 条款，不新造。每条给"判断依据（M 原文）+ 出图活写法（英文 prompt 锚点）"。

### 活留白（引 M4 · 留白是气韵的容器，不是没画完）
- **判断依据（M4 原文）**：留白承担"气之所聚"，像建筑进深，是视线休息区。判据：这块空白删掉后画面变窒息=留白是功能；变干净=只是没画到。
- **出图活写法**：不要写"白色背景 60%"（那是②的空洞），写 `the negative space is charged, not empty — it holds breath, like the vast white of a Southern Song边角 painting where the mountain corner still floats inside the void; the blank carries weight`（留白是"有气的虚"，不是死白）。
- **反模式**：纯白摄影棚背景 = 空洞②；"虚中有气"（留白里隐约藏着远山一角/一丝气韵走向）= ③。

### 藏锋线条（引 M3 · 最浅色不是白，最深色不是黑 + 04 形层）
- **判断依据**：宋人用茶白代纯白、墨色代纯黑，让光有材质；边缘收敛不外放（藏锋）。
- **出图活写法**：`edges are restrained, not sharp — lines recede rather than shout; no pure black or pure white, use warm off-white and deep ink-tone for material warmth`（线条"藏"不"露"，无纯黑纯白）。

### 墨分五色（引 01 灰调原则 · 用墨色浓淡做层次，而非靠高饱和）
- **判断依据（01）**：允许相邻色明度相近、饱和度接近（M2 退让）；用墨色浓淡层次拉开，不靠饱和。
- **出图活写法**：`five-tones ink gradation — the whole palette sits in one hue family, differentiation by value (lightest 70% / light / mid / dark / deepest) not by saturation; colors yield to each other`（全在一个色相内，靠 5 档明度拉开，不靠饱和撞色）。

### 静而不僵（引 04 意境层"神"层 + M8 藏三分）
- **判断依据（04）**：四层意境最高是"神/气韵流动贯通"——检验"整体是否活"。
- **出图活写法**：`the composition is still but not dead — a sense of quiet flow, as if the piece is breathing; hold back 30% of the emotion, let the viewer complete it`（静里有流动，藏三分让观者补完）。

### 一处反常焦点（引 05 senses_layer 第 5 条"奇"）
- **判断依据**：密度到顶时唯一还能加的一处；加对=活，加错（≥2处/居中/对称）=失效变"喜庆"。
- **出图活写法**：`one single deliberate anomaly — a small unexpected detail (a cinnabar point, an off-axis break) that holds the composition while everything else recedes`（一处反常托住整幅，其余退让）。

## 二、设计配方卡（款 × 气韵层 × 活方法 × 色彩系统）

> 这是"设计的系统"可复用的核心件。出图前**查配方卡**，不再临场手写。卡 = 款 + 目标气韵层 + 4 个活方法注入 + 1 个奇点 + 色彩灰度系统。

### 配方卡模板
```
【款】<现代款名>
【目标气韵层】③ 不可翻译的东方静气（默认）/ ② 泛现代（商业基线档）
【活方法注入（正向提示词前段，按此序）】
  1. 活留白：<charged negative space, not empty>
  2. 藏锋线条：<restrained edges, no pure black/white>
  3. 墨分五色：<five-tone value gradation, one hue family>
  4. 静而不僵：<quiet flow, hold back 30%>
【一处反常焦点（奇）】<cinnabar point / off-axis break，全幅唯一>
【色彩灰度系统】主色<低饱和> + 辅色<退让> + 奇点<缃黄≤3% 或 朱砂≤2%>，全幅 ≤2 主色相
【负向（2026-09-30 修正）】05 负向词（缠枝纹满铺/金箔满布/刺绣满身/影楼感/樱花/戏服感；立领盘扣可作改良结构）
```

### 示例配方卡：连帽卫衣 × ③
```
【款】连帽卫衣（hoodie）
【目标气韵层】③ 不可翻译的东方静气
【活方法注入】
  1. 活留白：背景留白 ≥55%，偏角（主体偏左 1/3），留白"有气"（虚里藏一丝气韵走向，非死白摄影棚）
  2. 藏锋线条：帽片/袖口/下摆边缘收敛不外放，罗纹收口柔和，无硬折
  3. 墨分五色：全幅雾灰蓝单色相，5 档明度（衣身最浅 → 帽里中 → 阴影深 → 底最重），不靠饱和
  4. 静而不僵：模特行走中衣摆轻飘（动态的静），藏三分情绪（平静不激动）
【奇点】帽里或领口一处极小缃黄内衬（≤3%）作为"反常焦点"，全幅唯一，托住整幅
【色彩灰度系统】雾灰蓝 #8A9BB0 主（低饱和）+ 象牙白辅（退让）+ 缃黄奇点 ≤3%
【负向（2026-09-30 修正）】缠枝纹满铺/金箔满布/刺绣满身/影楼感/樱花/戏服感/居中对称满幅/厚重闷灰；立领盘扣可作改良结构（改良对襟软开合/盘扣→现代纽扣）
```

> 注：示例把"奇点"放帽里缃黄内衬——这是 ③ 与 ② 的分界线。**② 是零奇点（全克制=平庸）；③ 是 90% 克制 + 1 处反常（活）。** 奇点必须极小（≤3%）且不破坏灰调。

## 三、出图侧 SOP（替代"临场手写"）

```
1. 选款 + 定气韵层：modern_key + 目标层（默认 ③；商业基线档用 ②）
2. 查 06 配方卡（本篇 §二 模板 / 已有卡）
3. 套活方法注入（§一 4 活参数 + 奇点，按序写进正向提示词前段，引用 M 编号）
4. 套色彩灰度系统（主+辅+奇点，≤2 主色相）
5. 负向：列 05 M9 negative_mandatory 全项
6. 出图（baoyu-image-gen / agnes-image）
7. 核验：
   - T 轨（annotate_translation T1–T6）→ 判"是否①失守/是否达标"
   - 06 气韵层判（本篇 §〇）→ 判"停② 还是到③"：
       去掉可解释元素后，还有没有"说不清的静气"？
       ③ = 有内在静气（西方觉得"好静说不出为什么"）
       ② = 空洞（西方觉得"就普通现代款"）
8. 到③=金标候选；停②=补活参数（留白加"气"/线条加"藏"/补奇点）重出
```

## 五、反模式沉淀

- **③ 不是"加回中式符号"**：那会退回 ①（符号拼接）。③ 靠活参数（活留白/藏锋/墨分/奇点），不靠立领缃黄。
- **② 不是交付目标**：干净无气韵 = 平庸。交付基线应是 ③；② 只作"商业基线档"（类比 v3.2 differentiation 分档思路，但 ② 是基线 ③ 是张力档）。
- **奇点不是越多越好**：≥2 处 / 居中 / 对称 = 失效变"喜庆"（M 奇条款），全幅唯一。
- **活参数必须引 M 编号**：不写"留白要好看"（空话），写"charged negative space（M4）"（可追溯）。
