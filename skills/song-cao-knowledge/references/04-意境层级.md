# 04 意境层级与纠偏清单

> 最高标准：意境 > 技法 > 形式。气韵优先。

## 四层意境

```
形式美（形）→ 技法美（法）→ 意境美（意）→ 气韵（神）
```

| 层 | 含义 | 检验问题 |
|---|---|---|
| 形 | 比例、轮廓合度 | 形制/构图是否合规矩？ |
| 法 | 笔墨/工艺纯正 | 技法是否正统（皴法/双钩）？ |
| 意 | 文人意趣传达 | 是否传达隐逸/山水/萧条淡泊？（宋人语：欧阳修"萧条淡泊"、苏轼"平淡天真"、黄休复"逸格"；非日式"物哀/侘寂"——判据词汇漂移见 05 方法库"宋日判据边界"） |
| 神 | 气韵流动贯通 | 整体是否"活"？（郭熙"气韵"非日式"寂"） |

## 宋韵评分（0-100）

| 区间 | 判定 | 动作 |
|---|---|---|
| ≥85 | 纯正宋韵 | 金标候选 |
| 70-84 | 基本符合 | 提示偏差项 |
| <70 | 需纠偏 | 触发完整纠偏流程 |

## 自动纠偏清单（每图必查）

1. 饱和度是否越界（对照 01 色彩谱系）
2. 元素密度是否过高（"减无可减"？）
3. 是否有大面积纯黑/纯白
4. 装饰是否冗余（无功能纹样应删）
5. 情绪是否张扬（宋式重含蓄）
6. 装裱边框是否干扰（以画心为准）

## 纠偏输出格式

1. 范式判定
2. 逐项检查（✅/⚠️ + 规则编号）
3. 偏差说明
4. 参数级修改建议
5. 宋韵评分（0-100）

## 语言风格（The Stylist）

- 优雅、含蓄、专业
- 像艺术策展人对话："此款领口若改为'圆领对襟'，是否更能体现宋式温润内敛的文人气质？"
- 引用依据时标注规则出处
